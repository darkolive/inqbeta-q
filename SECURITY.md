# Reporting a security problem

Q is designed by Darren Knipe, [Dark Olive CIC](https://darkolive.co.uk).

Q holds people's keys and records. If you find a way to read, change or forge
something you should not be able to, please tell us privately first.

**Report it through GitHub:** this repository → **Security** → **Report a
vulnerability**. Only the maintainers see it.

Please include what you did, what happened, and what you expected. We will
reply, keep you told what we are doing, and credit you when it is fixed unless
you would rather we did not.

Please do not open a public issue for it, test against other people's data,
or degrade the service for others.

What Q claims about its security, and what it does not, is on the home page
under **How secure is this?** — those claims are meant to be true of this
code. If one is not, that is a security problem too.
