## Fixed from Darren's tests

- **The voucher pages 404'd on the live site.** Three commits weren't pushed;
  the node had been updated but the site hadn't.
- **The buyer's credits stayed committed after settling.**
  - The shop owner's confirmation never reached the buyer.
  - Q now reads the bank's public ledger for the missing steps of your open
    agreements (`lib/catch-up.ts`). The first version ran before the vault had
    loaded; it now waits for the vault.
  - A step's message now carries where to answer it, so the shop owner can
    reach a buyer they've never linked with (`inqbeta.reply-to/1`).
- **The Committed card showed "4" when nothing was held.** Its big number is
  now what's held now. Committed and released in the window are beneath.
- **Spent didn't count the voucher sales.** Spent and Received now read each
  agreement step by step, the same way Committed does.
